# Big Daddy D Tail on Wheels

One-page mobile wash and detailing prototype for Big Daddy D Tail on Wheels.

The current build includes a SATCORP prototype watermark and placeholder contact details.

## Deploy with Vercel

Import this repository in Vercel, keep the default framework preset, and deploy. The included `vercel.json` configures static hosting, clean URLs, and basic security headers; no build command or environment variables are required.
